# 비주얼 스타일 가이드

## 핵심 방향

> 어두운 던전 속 따뜻한 식당

게임 세계는 위험한 던전과 연결되어 있지만, 플레이어의 식당은 모험가들이 안심하고 돌아오는 따뜻한 공간으로 표현한다. 화면 대부분은 짙은 남색과 갈색으로 정리하고, 조작 가능한 요소와 보상은 금색·주황색으로 강조한다.

## 후보 비교

| 후보 | 장점 | 단점 | 결정 |
|---|---|---|---|
| Kenney Tiny Dungeon | 작은 화면에서 선명하고 톤이 일관됨 | 식당 가구와 UI 선택지가 적음 | 보류 |
| Kenney Roguelike/RPG Pack | 방·가구·아이콘·패널을 한 팩에서 확보 가능 | 16px 원본이므로 정수 배율 확대 필요 | **기본 스타일로 확정** |
| Kenney Roguelike Indoors | 실내 가구 구성이 풍부함 | 다른 팩과 혼합하면 색감 차이가 생길 수 있음 | 예비 후보 |

## 확정 에셋 스타일

- 기본: **Kenney Roguelike/RPG Pack의 16×16 픽셀 판타지 스타일**
- 캐릭터 보완: Kenney Roguelike Characters
- UI 보완: Kenney UI Pack (RPG Expansion)
- 확대 방식: 2×, 3×, 4× 같은 정수 배율만 사용
- CSS/Canvas: `image-rendering: pixelated` 유지
- 픽셀아트와 벡터·일러스트풍 에셋을 같은 화면에서 혼용하지 않음

## 색상 팔레트

| 역할 | 색상 | HEX |
|---|---|---|
| 화면 바깥 배경 | 짙은 남색 | `#171923` |
| 식당 실내 배경 | 어두운 갈색 | `#2A211C` |
| 기본 패널 | 나무색 | `#49372B` |
| 깊은 패널 | 짙은 나무색 | `#2F251F` |
| 주요 강조 | 따뜻한 금색 | `#D9A441` |
| 버튼·불빛 | 주황색 | `#D97732` |
| 기본 글자 | 크림색 | `#F3E7D0` |
| 보조 글자 | 연한 회갈색 | `#B9AA96` |

| 위험·실패 | 붉은색 | `#C9574F` |

### 재료 등급

- 일반: `#999999`
- 고급: `#4A90D9`
- 희귀: `#D9A94A`

## 사용 비율

- 60%: 짙은 남색·어두운 갈색 배경
- 30%: 나무색 패널·크림색 텍스트
- 10%: 금색·주황색 강조

## 화면별 적용 규칙

### 시작 화면

- 배경은 짙은 남색 또는 어두운 식당 내부
- 제목은 금색
- 시작 버튼은 주황색, 금색 테두리

### 길드 게시판

- 게시판과 카드 배경은 나무색
- 선택 가능한 재료는 금색 테두리나 주황색 표시
- 카테고리는 보조 글자색으로 표시

### 모험가 리빌

- 결과 공개 전에는 배경 밝기를 낮춤
- 일반·고급·희귀 색은 텍스트뿐 아니라 테두리 또는 아이콘에도 함께 사용
- 색만으로 등급을 구분하지 않고 등급 이름을 반드시 표시

### 요리 판정

- 성공은 초록색과 `성공` 문구
- 실패는 붉은색과 `실패` 문구
- 냄비·불꽃처럼 조리와 직접 관련된 요소에만 주황색 사용

### 서빙 러시

- 정상 인내심은 금색 또는 크림색
- 낮은 인내심은 붉은색과 흔들림·경고 아이콘을 함께 사용
- 손님과 요리 카드의 클릭 영역은 최소 44px 이상 확보

## 접근성 원칙

- 상태를 색상만으로 전달하지 않고 텍스트·아이콘을 함께 표시한다.
- 크림색 본문과 어두운 배경 조합을 유지한다.
- 키보드 포커스에는 밝은 외곽선을 표시한다.
- 작은 픽셀 아이콘에는 짧은 텍스트 라벨을 병기한다.

## 개발 적용 위치

색상은 `css/style.css`의 `:root` 변수로 관리한다. 임의의 HEX 값을 화면별로 다시 작성하지 말고 기존 변수를 재사용한다.
