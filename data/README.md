# 데이터 파일 작성 가이드

이 폴더의 JSON 파일들은 비개발 담당자가 직접 채워서 커밋합니다.
"예:"로 시작하는 값은 예시이니 실제 내용으로 바꿔주세요.

- ingredients.json: 재료 목록과 등급별 등장 확률
- recipes.json: 레시피와 재료 조합, 맛 매칭 보너스 규칙
- dialogue.json: 모험가/손님 대사
- upgrades.json: 라운드 사이 업그레이드 카드 문구

작성 후 커밋 메시지는 `docs: 재료/레시피 데이터 초안 작성` 같은 형식으로 남겨주세요.
개발자가 이 파일을 그대로 코드에서 불러다 씁니다.
